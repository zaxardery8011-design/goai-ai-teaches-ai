# 我們實際怎麼用

去識別過。這是做法，不是某一家的後台教學。

租雲端顯示卡的平台時，人看不懂後台，就叫助手自己去。順序固定成三步，夠用就停：

1. **CDP**。開瀏覽器看頁面，人坐在旁邊看它點。
2. **API**。頁面上做不到、對方文件有寫接口，才改走接口。
3. **SSH**。頁面和接口都不夠，才進你租的那台機器。沒有租那台、沒有人授權，不做這步。

國外網站，以及各家網頁版 AI（影片生成、聊天），也多半是叫助手用 CDP 操作。

我們收成的形狀是：一個總管接在 Telegram 或 LINE，你講一句，它去用各家工具。對照的是你自己開各家 App。

## 利弊

| | 一個總管，你講一句 | 自己開各家 App |
|---|---|---|
| 上手 | 要先準備 AI 專用瀏覽器，第一次比較麻煩 | 各家註冊完就能點 |
| 日常 | 一句話，它去各家頁面做事 | 每個 App 自己開、自己點 |
| 看得到過程 | 瀏覽器開在旁邊，點了什麼看得到 | 過程就是你自己在點 |
| 風險 | 登入集中在那顆瀏覽器；有的條款不允許自動化 | 帳號仍在各家；比較不容易踩自動化條款 |
| 適合誰 | 已經有助手、想少切換視窗的人 | 想每一步自己看，或條款不允許代操作的人 |

## 煞車

有些服務條款不允許自動化。動手之前先看規定。規定不允許，就改由人自己點，或改走他們公開提供的 API。不要為了快，去繞過驗證或條款。
