# 四個成熟開源，各一句什麼時候用

星數是約數，查詢日 2026-10-29。四個當天都未封存。要引用星數時，自己再查一次。

- `ChromeDevTools/chrome-devtools-mcp`（Chrome 官方，約 5.4 萬星）：你已經開好只綁本機的除錯埠、要助手沿官方工具操作這顆 Chrome 時用。
- `microsoft/playwright-mcp`（約 3.9 萬星）：頁面要穩定定位、你想把 Playwright 那套交給助手時用。
- `browser-use/browser-use`（約 12 萬星）：你想用一段話讓程式自己規劃點哪、打什麼時用。
- `puppeteer/puppeteer`（約 9.6 萬星）：你要自己寫腳本控制頁面，而不是先接一個對話助手時用。

四個都不必為了這包先裝。你的 AI 環境裡已經有瀏覽器工具，就用它已經有的，再對照上面「什麼時候換」。
