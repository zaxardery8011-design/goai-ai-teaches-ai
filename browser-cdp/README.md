# 讓 AI 用你的瀏覽器做事

你講一句，AI 開一顆你看得到的瀏覽器去完成。人留在旁邊。送出鍵留給人。

## 能做到什麼

1. **查資料**。打開公開頁，把你要的數字或句子抄出來，並寫它從哪一段來。
2. **填表**。草稿填進格子。送出、付款、刪除，停下來等你按。
3. **抓網頁**。把一頁的正文收成一份檔，標讀了哪些區塊、沒讀哪些。
4. **批次整理**。同一份清單上的網址逐個打開，摘成一張表。一筆對不上就停在那一筆，不假裝整份都好了。
5. **巡平台、整理留言**。沿你給的關鍵字，把同一個平台上的留言收成一份：誰說的、哪一則、還沒回的。草擬回覆可以，送出留給人。沿關鍵字把留言收成清單這件事，有人叫它海巡；它就是這一項，不另開一支流程。

登入頁、驗證碼、雙因素：停，等人。不要輸入帳密。

## 先問使用者

1. 這次是上面五件裡的哪一件？
2. 除錯埠是多少？只接受綁在本機 `127.0.0.1` 的埠。
3. 這顆瀏覽器是不是專門給 AI 用的？人平常在用的那顆不要接。

問完再連。安全十條沒讀過，不要連。

## 驗收

- 做完指得出打開了哪一頁、做了哪一件。
- 帳密沒有進過對話。cookie 沒有被抄出來。
- 凡是會公開或會改資料的按鈕，都沒有按下去，除非使用者自己按。
- 批次時，每一筆有結果或有停住的原因。沒有「應該都好了」。
