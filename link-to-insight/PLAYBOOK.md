# 看懂一個連結：怎麼想

`README.md` 管怎麼抓。本檔管怎麼想。兩份一起用。

## 九個切入點（實際使用順序）

### 1. 先問這個連結跟使用者什麼關係

同市場、搶同一群人 → 挖到價格、客群、漏斗、弱點，最後回答「我們差在哪」。

只是寫得好、或一則新聞 → 挖寫法或對帳就夠，不必查價格。

問句：他賣什麼、賣給誰？一個陌生人從看到這頁到付錢，中間幾步？

### 2. 使用者的判斷，和資料能證明的，分兩欄

「我確定他用 AI 代操」是心證。資料能看到的是節奏突然變準、回覆又短又快、早期一批套模板的案例。沒有草稿、排程、API 紀錄，就寫「線索強，沒有直接證據」。

不要把確信寫成已證實。也不因為缺直接證據就說他錯。

問句：這句話換成法庭，算證據還是心證？

### 3. 抓全母體，不抽樣；抓完先看最早日期

快速捲動會少抓一大半。實測同一帳號，快爬只拿到約一成到三成，放慢才接近全量。

判斷有沒有抓全：粉絲數與經營時間，配不配你抓到的篇數。配不上就重爬。

### 4. 先算數再讀文

讀之前先跑四組數字，它們告訴你該讀哪幾篇：

| 數字 | 看什麼 |
|---|---|
| 每月、每日篇數 | 節奏有沒有一天突然變 |
| 讚或瀏覽的中位、前 5% 佔比 | 平均有量，還是靠少數爆文 |
| 回覆延遲與長度 | 回得多快、多短 |
| 導流連結出現在哪一段 | 漏斗怎麼接 |

問句：哪一天、哪一類、哪幾篇，數字不正常？

### 5. 找變化日

置頂改了、節奏改了、主推改了，那天就是策略轉向。變化日前後各讀幾篇，比從頭讀到尾快。

### 6. 用高低互動組對照，不要照作者自己教的規則

作者置頂在教寫作技巧，真正撐流量的可能是人物關係與提問。做法：讚數或瀏覽前 20% 對後 20%，看哪些特徵在高組比較常出現。

這只是同時出現，不是因果。樣本只有這一位，限制要寫出來。

問句：他教別人的，跟他自己真正爆的，是同一件事嗎？

### 7. 漏斗從簡介一路對到價格頁

對帳順序：簡介 → 置頂 → 文內連結 → 官網 → 價格頁 → 退費條款。

價格只信官網原頁。粉絲、續約、案例數字一律標自述。

### 8. 讀留言區，看留言是不是在收名單

重點不是留言多不多，而是「留言 → 私訊 → 諮詢」有沒有被設計成一條路。

有人用「留言達到門檻才教」衝互動。那是平台會降權的誘餌，分析可以記，做法不要借。

### 9. 借鏡要落到一個會改的檔，再用自己的數字驗

報告寫完不算完。發現要改哪個檔、哪個欄位？改了之後用什麼數字知道有沒有用？

證據衝突時，先不改設定，交給之後自己帳號的互動數據。

## 這次犯過、要防的錯（操作層）

1. 捲動太快，抓完沒先看最早日期。
2. 派下一個人之前，把篇數寫錯。數字寫進說明前自己先算一次。
3. 一句話寫太滿。沒逐則核對過的，用推測語氣。
4. 在錯誤的環境讀中文表格，亂碼，浪費一輪。統計用能正確處理該編碼的工具。
5. 驗證的人沒拿到全部來源，會把真的東西判成無證據。綜合的人愛寫「一律」。

## 一次只記五個數字，看方法有沒有進步

| 指標 | 怎麼算 |
|---|---|
| 抓全率 | 第一次抓到的篇數 ÷ 最終篇數 |
| 回件抽驗通過率 | 對得上的筆數 ÷ 抽驗筆數 |
| 深讀挑錯站得住比例 | 站得住的條數 ÷ 總條數 |
| 借鏡落地數 | 真的改了設定或流程的條數 |
| 落地後效果 | 兩週後自己帳號上，該做法的互動跟其他題比 |

## 兩個去識別實例（方法，不是名單）

**新號、同題、提示詞漏斗。** 十幾天、幾千粉。高互動是一張圖帶走的清單，開通知類遠高於留言換教學。收入在個人頁與貼文上是兩個對不上的數字，標未驗證。題材撞到「技能包、一人公司」。帶走的判斷：清單圖與「先說出讀者的反駁」可看；收入開場、留言門檻、把人趕進私訊領提示詞，不借。同題材的差別寫在本包 README：我們帶走資料夾，讓 AI 讀完能做。

**本業寫進短文的代操帳。** 幾百篇主文。高瀏覽開頭常借一個人再接自己的反應。本業詞在高瀏覽組更密。文末要人私訊的很少。代操流程她自己寫在文裡（訪談、月報、試用期），全部當自述。方法：高低組對照＋自述與頁面數字分開寫。
