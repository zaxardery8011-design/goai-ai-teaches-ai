# 5. 外部回件要抽驗

其他模型、搜尋代理、外部顧問的回件，構想可以留，來源要抽。統計數字最弱。標了「已驗證」的提高抽驗，不要降低。

完整步驟在 `skills/claim-spotcheck`。這裡只講為什麼這條是「教 AI」的一部分：你抽驗的結果要寫回檔，下一輪才不會把同一批 404 再引用一次。

## 做法

- 依 claim 類型分層，不是整份信或不信。
- 清單要引用，就每筆都打。抽樣 3 筆攔不住剩下的假來源。
- 否定斷言另抽。排除清單不是窮盡。
- 命令原始輸出貼進表。轉述不算。
- 對不上的標出來。構想仍可用，來源不得背書。

## 真實例子（去識別）

一份回件列 9 個 GitHub 專案當推薦。抽 3 筆的話，攔不住另外 4 個 404。同一份裡還有星數差一個數量級、授權名稱不對、被說成持續更新但其實已封存。

另一份：學術連結的編號是真的，打開標題是語音蒸餾，回件卻拿它當多智能體論文。編號能解析，不表示那句話被論文支撐。

再一份：創作者偵察的拆解，抽 11 筆網址與原句，11 筆對得上。同一週另一家外部淺查沒抽，引用前才補。抽驗通過率要記下來，當方法有沒有進步的數字，不是當感覺。
