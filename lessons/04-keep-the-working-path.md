# 4. 成功路線記下來，照走

做對一次之後，下一輪只呼叫那條路。技能保持薄：不在技能裡分叉重寫。要改行為，改那一條已經驗證的管線。

分叉的代價是：兩個地方各改一半，下一輪不知道以誰為準。

## 做法

- 收斂即興腳本。五支臨時 runner 做同一件事，留共同骨架，刪其餘。
- 技能寫「呼既有管線」，列出參數，不重寫下載與轉錄。
- 人點頭的底模寫進會被讀到的檔。舊路留作對照，預設不走。
- 公式庫一份檔，寫作技能與自動草稿共用。改那一份即生效。

## 真實例子（去識別）

影片消化曾經有五支即興腳本，參數大同小異。收成一條管線之後，技能只做三件事：呼叫、驗檔、失敗透明。蒸餾格式要改，去改管線，技能不動。

聲音線點頭用台灣口語底模之後，預設路線就是它。舊克隆專案還能跑，預設仍不走。有一輪忽略這條，拿舊權重唸新稿，字錯率回到不可用。成功路線沒被當成預設，等於沒記。
