# 蒸餾自己的聲音

兩條線，不要混。

| 線 | 蒸餾的是 | 產出 | 難度 |
|---|---|---|---|
| 音色 | 你說話的聲帶 | 模型或試聽檔，用你的聲音唸新稿 | ★★★★★ |
| 口吻 | 你打字的習慣 | 一份口吻總表，AI 代筆前先讀 | ★★☆☆☆ |

整體（兩條都做、音色做到能唸稿）：★★★★☆。口吻可以今天做完。音色要錄音、對稿、選開源專案、有 GPU。

先問使用者做哪一條。兩條都要就先口吻、後音色。口吻不依賴訓練機器。

- 音色 → `sound.md`
- 口吻 → `tone.md`
- 我們踩過的坑 → `pitfalls.md`（兩條都先讀坑）

## 一句原則

有成熟開源專案的題目，先去程式託管網站找現成做法與 issue，再只跑一條路。本機一輪輪試、每輪試聽檔段數還不一樣，人會對不到要聽哪一段。
