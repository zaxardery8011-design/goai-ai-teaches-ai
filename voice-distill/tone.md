# 口吻：從你自己打過的字，蒸餾成總表

音色是聲帶。口吻是你打字時真正會用的詞、斷句、降調。對外代筆先讀總表，再套文案公式。

難度：★★☆☆☆  
時間：有現成聊天匯出，數小時內可出第一版。  
硬體：一般筆電。不需要 GPU。  
成本：匯出免費。若用模型幫你分類對話，算該模型的用量。

## 做什麼

1. 匯出你本人打的對話。LINE、Telegram、論壇回覆、你自己在社群留下的回覆。
2. 只留本人。轉貼、別人的話、你轉發的長文，分開。
3. 數詞頻。只收本人而且數得到 ≥3 的。
4. 分開「對自己的 AI／助理下指令」與「對外人講話」。指令詞不進對外稿。
5. 寫硬規則（寫完可逐條機械檢查）。
6. 寫兩三種場景模板，示範只用入庫的詞。
7. 以後代筆先讀這份。跟舊側寫衝突，以這份為準。

## 要什麼素材

- 你自己的匯出檔。時間跨度至少數週，最好含你對外回過的留言。
- 一份「這是我本人」的判定方式：暱稱、帳號、或匯出裡的發言者欄。
- 不要把客戶真名、電話、信箱帶進總表。抽到個資就停，先洗。我們做過一次要拿去訓練小模型的語料，抽查仍有客戶姓名，整批停訓。

## 用什麼工具

- 計數：任何能讀純文字、跑正規表示式的腳本。Python 或試算表都可以。
- 分類（可選）：用模型幫每則打標（回答、附和、分享做法、吐槽、下指令）。人抽驗每類至少 3 則。分類錯了會污染詞頻。
- 去識別：姓名、信箱、網址、電話各掃一次。對照組用一份你明知含電話的檔，證明掃描指令有效。

不需要 LoRA、不需要微調聊天模型。總表本身就能讓代筆像你。要再訓練小模型，等去識別抽查為零再談。那一層難度另計，本檔不展開。

## 總表建議結構（方法，不是某個人的詞）

1. **硬規則**：斷句、標點、禁用的語氣詞、第一行做什麼、收尾最多幾個語氣。
2. **已驗證的更正**：你本人在公開場合實際打過、和想像中不一樣的地方。
3. **口語關鍵字庫**：只收 ≥3。每詞附一則原句。任務點名但沒過門檻的，另表列出，不入庫。
4. **工作指令 vs 對外**：對助理說的密語，對外拿掉。
5. **場景模板**：社團回別人、回自己帖下的留言、坐下來寫的長文。三種規則可以不同（短回空格斷句、長文才用句號當呼吸）。

## 步驟（給執行的 AI）

1. 問匯出檔在哪、哪一個名字是本人。
2. 掃個資。命中則停，列出類別與筆數，不要把原句貼進總表。
3. 詞頻。≥3 入庫。未滿 3 的詞，即使聽起來很像他，也不進硬規則。
4. 抽 5 則分類給使用者看。他改標就改規則。
5. 硬規則寫成「寫完可逐條打勾」。
6. 模板只用入庫的詞。不要另編比喻故事，除非他的原句裡真的有。
7. 驗收：拿一則他沒進訓練窗的對外回覆，遮住名字，看模板生出來的稿像不像。不像就改規則，不要加形容詞硬修。

## 驗收

- 總表存在。硬規則可逐條檢查。
- 入庫詞都有次數與一則原句。
- 指令詞表與對外詞表分開。
- 個資掃描 0 命中；同一指令掃一份已知含個資的檔，有命中。
