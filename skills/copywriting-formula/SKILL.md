# copywriting-formula

把對外文案從「憑感覺寫」變成「套公式寫」。上位規範是留帳體。公式庫管節奏。兩者衝突，以留帳體為準。

公式骨架在同夾 `formulas.md`。本檔管何時用、怎麼疊、出稿前掃什麼。

## 何時用

要寫或改給外人看的字。程式、研究報告、內部任務單，不用這份。

## 留帳體（所有對外文稿先套這個）

### 敘事主體是使用者本人

主角是他在講一件他觀察到的事。AI 是他做出來的東西，不是對外稿的第一人稱。

不要寫成品牌小編或「AI 自我介紹」。正文不要出現他對內部夥伴的暱稱。

對外提到他的 AI，用他指定的稱呼。他沒指定就問一句，不要自己取名。

### 四段骨架（固定順序）

1. **系統回報了什麼** — 具體對象＋數字，不是抽象形容。
2. **聽完的判斷** — 為什麼這件事對他重要、他因此決定了什麼。
3. **白話講給讀者** — 你會不會踩到、要不要在意、什麼情況才需要。
4. **留帳段** — 驗了什麼、驗到哪一層、哪裡原本想錯了。

第 4 段不可省。別人的貼文停在「我做出來了」。這裡多一句「我怎麼知道它真的成了」。

### 時間不講死

素材多半是過去的例子。寫「今天早上」會在重發時變假。

用「有一天」「那次」「後來」。常態行為才用「每天」。方法論用「到現在還沒修好」，不要用「到今天」。

### 三個誠實動作（缺一不可）

1. 數字標查證時間與來源。
2. 沒驗的寫「這點還沒驗」。
3. 自己錯了就寫進去。

### 視覺（有配圖時）

圖要看得到帳：before → after、勾叉、數字對照。一個系列一個主色。

## 怎麼用

1. 先向使用者要真素材。沒有親身經驗、數字或案例，換題或不寫。模板不能補造內容。
2. 從 `formulas.md` 依場合選一套當內部節奏。不確定就用「綜合式」。
3. 先套留帳體四段，再把選中的公式填進節奏。
4. 疊誠實鐵律：不杜撰第一人稱經歷、實測、收入、成果。轉述就寫轉述。
5. 出稿前跑「去 AI 味」與 `formulas.md` 文末清單。

## 抓耳四條（短文可用，仍在留帳體之下）

1. **反直覺指令** — X 發生時，不要做第一反應 Y。讀者認得自己的下一步時用。
2. **答不出來的一問** — 問一個該有答案的事實，停在問句。手上沒有對方的數字時用。
3. **兩筆帳** — 他看的那一欄旁，攤開沒對上的那一欄。
4. **關卡，不打分數** — 只說卡在哪一關。數量沒有帳就不寫。

一篇只留一個詞，不講整套。問題出現的下一句就給答案。短文不掛小標。

別人的結果只寫前後各一筆，加一句原話。沒重跑就寫「這筆我沒親自重跑」。

不借：稀缺句、沒出處的收入與漲粉數字、正文塞購買連結、恐嚇用詞。

## 去 AI 味（出稿前必掃）

命中就改：

- 「不是 X，而是 Y」一篇頂多一次。
- 賦能／打造／釋放潛能／錯綜複雜／深入探討／在當今這個時代／值得一提的是 → 換成白話。
- 「不僅…更…甚至…」連發 → 拆掉。
- 「總而言之」「扮演關鍵角色」這種沒資訊的收尾 → 刪。
- 沒有具體細節、沒有卡關、句子長短一樣工整 → 補真實顆粒。
- 唸出來不像使用者本人會講的話 → 重寫。口吻規則若使用者另有總表，以總表為準。

## 紅線

- 公式是骨架。讀起來要像真人。
- 沒有真素材就停。
- 多套輪替是為了練不同發文邏輯，不是為了每天都發。

## 驗收

- 四段都在，第 4 段寫得出驗了什麼。
- 每個數字有來源或標未驗。
- 去 AI 味清單 0 命中，或命中處已改。
- 使用者能指著某一句說「這是我的料」。
